DEM の 1 画素に入っている数（DN値）は、24bit の整数 x です。 標高タイルは、この x を R・G・B に 8bit ずつ詰めて画像にしています。詰め方は方式ごとに違います。

x と標高の関係

横軸は DN の x（0〜16777215）、縦軸は標高。グラフをクリック／ドラッグするとその x を読み込みます。

なぜ標高を RGB に詰めるのか

普通の画像として読める

ブラウザも GPU も、PNG や WebP の画像ならそのまま扱えます。標高専用の形式を用意しなくて済みます。

PNG で圧縮できる

可逆圧縮の画像形式なら、値を壊さずにデータを小さくできます。

タイル地図と同じ配信

地図画像と同じ z/x/y のタイルとして配れるので、既存のタイル配信の仕組みに載せられます。

出典（式）

  • Terrarium(R*256 + G + B/256) - 32768
  • Terrain-RGB-10000 + ((R*256*256 + G*256 + B)*0.1)
  • 地理院x = 2^16 R + 2^8 G + B、u = 0.01、x = 2^23 が無効、x > 2^23 は x - 2^24
